# 🎰 JavaScript Slot Machine

A beginner-friendly slot machine game built with JavaScript that runs in the terminal.

## Features

- Deposit money
- Choose the number of betting lines
- Place bets
- Spin the slot machine
- Calculate winnings
- Display the results in the terminal

## Technologies Used

- JavaScript
- Node.js
- `prompt-sync`

## How to Run

1. Clone this repository.
2. Open the project folder in the terminal.
3. Install the dependencies:

```bash
npm install
```

4. Run the game:

```bash
node project.js
```
